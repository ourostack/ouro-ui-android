The kit now has Switch, Select and Field (OuroSwitch, OuroSelect, OuroField), and TextField and Checkbox match core's 1.1.0 specs, with the error and the description carried as the control's own semantics. They sit beside ItemGroup, Tabs, TabBar, Sidebar, Dialog, Sheet, ConfirmDialog and the components before, with their baseline images recorded. Each passes the claims its spec names in the Robolectric tests, and CI prints one line per spec case.

**Checked on:** CI only. The maintainer owns no Android device, so nothing here has run on real hardware yet. If you have a device and something differs, please open an issue.

**Install:** add `maven { url = uri("https://ourostack.github.io/ouro-ui-android/maven") }` to your repositories and `implementation("bot.ouro.ui:ouro-hx:0.9.0")`. The Maven files are also attached below.
