Android draws Ouro's composed tree: the UI an agent composes for a person, checked against your app's catalog, where every button is one of your declared actions with its consent class.

- **`OuroComposedSurface`:** draws the tree from an MCP tool result's `structuredContent.ouro` (`OuroComposed.read`) with Ouro HX.
  - Read and write buttons press at once.
  - A consequential button opens a confirm sheet built from your catalog and the input, and presses only on confirm.
  - A person-only button calls `onHandoff` and never presses.
  - Fields write the data model, and a bound button sends what the person entered.
  - Nothing in it lets an agent press: an agent calls the action through its AppFunction.
- **`bot.ouro.ui.hx.composed`:** core's `composed.mts` (v0.18.0) ported to Kotlin: the catalog, `validateTree`, JSON Pointer reads and writes, `resolveButton`, `personPress` and `confirmSheet`. It's tested against every tree core's conformance cases hold, and core's forged trees are rejected for the same reasons.
- **Four components from core's specs:** `OuroCheckbox`, `OuroTextField`, `OuroSeparator` and `OuroDescriptionList`. Every claim their specs make is checked.
- **`LocalOuroSurface`:** components inside an outlined `OuroCard` measure contrast against the card, not the page.
- **Core 0.18.0:** the pin moved from 0.15.0. `scripts/provenance.mjs` also vendors files the dist doesn't carry (the conformance cases), by the tag's commit and SHA-256.

**Limits:** Android reads no A2UI messages: send Ouro's tree, not an A2UI stream. The default image loader fetches https only. A confirm sheet's rows come from your catalog, not the tree, because core's validator doesn't check them yet (ourostack/ouro-ui-core#88).

**Checked on:** CI only. The Robolectric tests run core's claims, the composed cases and the snapshots. The sample's X-ray and its composed card run on an Android 17 (API 37) emulator. The maintainer owns no Android device, so nothing here has run on real hardware yet. If you have a device and something differs, please open an issue; collaborators are welcome.

**Install:** add `maven { url = uri("https://ourostack.github.io/ouro-ui-android/maven") }` to your repositories and `implementation("bot.ouro.ui:ouro-hx:0.2.0")`. The Maven files are also attached below.
