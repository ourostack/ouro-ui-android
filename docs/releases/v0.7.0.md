The kit now has Tabs, Dialog, Sheet and ConfirmDialog (from core v1.3.0's and v1.4.0's specs) beside the components before. Each passes the claims its spec names in the Robolectric tests, and the Dialog, Sheet and ConfirmDialog run on the CI emulator too. A ConfirmDialog with an action words its question from the action's declared confirmation.

**Known gap:** on a Sheet whose body scrolls, a drag inside the body scrolls instead of dismissing; the handle and the padding still dismiss.

**Checked on:** CI only. The maintainer owns no Android device, so nothing here has run on real hardware yet. If you have a device and something differs, please open an issue.

**Install:** add `maven { url = uri("https://ourostack.github.io/ouro-ui-android/maven") }` to your repositories and `implementation("bot.ouro.ui:ouro-hx:0.7.0")`. The Maven files are also attached below.
