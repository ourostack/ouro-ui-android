The kit now has Message, ReactionBar, MessageList and Composer (`OuroMessage`, `OuroReactionBar`, `OuroMessageList`, `OuroComposer`), built to core v1.7.0's chat specs, beside ConversationList from 0.10.0. Message is one chat message with its author, time and state, as a bubble on the author's side or, for the system role, as centred muted text. ReactionBar shows reaction pills with counts. MessageList is a conversation that announces new messages politely. Composer is a message box with a Send button that sends on Enter and says why when it can't. Each passes the claims its spec names in the Robolectric tests, has its baseline images recorded, and CI prints one line per spec case.

**Checked on:** CI only. The maintainer owns no Android device, so nothing here has run on real hardware yet. If you have a device and something differs, please open an issue.

**Install:** add `maven { url = uri("https://ourostack.github.io/ouro-ui-android/maven") }` to your repositories and `implementation("bot.ouro.ui:ouro-hx:0.11.0")`. The Maven files are also attached below.
