The first Ouro UI kit for Android: a Compose theme and four components for people, and AppFunctions for agents, from one action declaration.

- **ouro-hx 0.1.0:** `OuroTheme` from core's tokens (six themes, light and dark, increased contrast, reduce motion), and `OuroButton`, `OuroBadge`, `OuroCard` and `OuroItem`, rendered by hand from core's specs (vendored by SHA-256 in `core-provenance.json`).
- **ouro-actions 0.1.0:** one path for a person's press and an agent's AppFunction call. A person-only action refuses agents with core's typed refusal. A consequential one is refused until the app's `confirm` asks the person.
- **The generator** (`tools/ouro-actions-android.mts`): declarations become `OuroActions.kt` and `doors.json`.

**Checked on:** CI only. Core's claims for all four components run in Robolectric, the snapshots cover light, dark, increased contrast and 200% text, and the sample's X-ray runs on an Android 17 (API 37) emulator. The maintainer owns no Android device, so nothing here has run on real hardware yet. If you have a device and something differs, please open an issue; collaborators are welcome.

**Install:** add `maven { url = uri("https://ourostack.github.io/ouro-ui-android/maven") }` to your repositories and `implementation("bot.ouro.ui:ouro-hx:0.1.0")`. The Maven files are also attached below.
