The kit now has TabBar and Sidebar (OuroTabBar, OuroSidebar) beside Tabs, Dialog, Sheet, ConfirmDialog and the components before, with their baseline images recorded. Each passes the claims its spec names in the Robolectric tests.

**Checked on:** CI only. The maintainer owns no Android device, so nothing here has run on real hardware yet. If you have a device and something differs, please open an issue.

**Install:** add `maven { url = uri("https://ourostack.github.io/ouro-ui-android/maven") }` to your repositories and `implementation("bot.ouro.ui:ouro-hx:0.8.0")`. The Maven files are also attached below.
