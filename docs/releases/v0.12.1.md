This is the first release published to Maven Central. `bot.ouro.ui:ouro-hx` and `bot.ouro.ui:ouro-actions` are signed with the release key in `docs/signing-key.asc`, so `mavenCentral()` is all an app needs. The components are the same as v0.12.0. CI now also checks what TalkBack speaks for Table, and its swipe navigation through a table, on the CI emulator.

**Checked on:** CI only. The maintainer owns no Android device, so nothing here has run on real hardware yet. If you have a device and something differs, please open an issue.

**Install:** `implementation("bot.ouro.ui:ouro-hx:0.12.1")` with `mavenCentral()` in your repositories. The kit's GitHub Pages Maven repository (`https://ourostack.github.io/ouro-ui-android/maven`) still has this and every earlier release, and the Maven files are also attached below.
