The kit now vendors ouro-ui-core v0.21.0, which follows the web tokens through v1.3.331. The Android token file (`OuroTokens.kt`), the composed catalogs and the actions generator come from that release, and the sample's generated actions and catalog are regenerated from it. No API of the library changed.

**Checked on:** CI only. The maintainer owns no Android device, so nothing here has run on real hardware yet. If you have a device and something differs, please open an issue.

**Install:** add `maven { url = uri("https://ourostack.github.io/ouro-ui-android/maven") }` to your repositories and `implementation("bot.ouro.ui:ouro-hx:0.6.0")`. The Maven files are also attached below.
