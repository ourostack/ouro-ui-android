The kit now has Table (`OuroTable`), built to core v1.8.0's table spec. It is a data grid with a caption, column headers and rows. TalkBack reads it as a table: the root is named by the caption, each header is a heading with its row and column, and a sortable header is a button that reads "sorted ascending" or "sorted descending". With `onRowPress` a row is one button named by its row header. Columns shrink to fit a narrow screen, and below 64dp the table scrolls sideways in its own region. It passes the claims its spec names in the Robolectric tests, has its baseline images recorded, and CI prints one line per spec case (`table/<case>`).

**Checked on:** CI only. The maintainer owns no Android device, so nothing here has run on real hardware yet. If you have a device and something differs, please open an issue.

**Install:** add `maven { url = uri("https://ourostack.github.io/ouro-ui-android/maven") }` to your repositories and `implementation("bot.ouro.ui:ouro-hx:0.12.0")`. The Maven files are also attached below.
