# Ouro UI for Android

Ouro UI's native kit for Android: core's components in Jetpack Compose, and AppFunctions for agents, generated from [ouro-ui-core](https://github.com/ourostack/ouro-ui-core)'s one `defineAction` declaration.

**Status: being built.** The plan is the [native-kits decision record](https://github.com/ourostack/ouro-ui-core/blob/main/docs/decisions/2026-11-14-native-kits.md): one Compose kit, component specs vendored from core by hash, and only the rendering written here.

## No Android devices here: collaborators welcome

The maintainer owns no Android phone or tablet. Everything in this repository is checked on Android emulators in GitHub's CI, never on a real device. If you have Android devices and want to help, open an issue or a pull request from a fork; you're very welcome. Collaborators join as outside collaborators on this public repository or through forks.
